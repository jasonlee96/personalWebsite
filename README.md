# personalWebsite

Jason Lee's personal portfolio site, built with Next.js and Tailwind CSS.

Website: https://jasonlee96.github.io/personalWebsite/

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build   # static export to ./out
npm run serve   # preview the production build locally
```

Content lives in `src/data/profile.js` — update work experience, projects,
skills, and contact info there.
